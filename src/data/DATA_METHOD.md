# 資格データと接続の作成基準

## 収録対象

- 公式サイトで現行資格として案内されていること
- 公式の試験範囲、試験ガイド、出題項目を確認できること
- 日本国内から受験を検討できる情報系資格であること
- Applied Skills、修了証、学習コースだけのものは資格に含めないこと
- 廃止済み、終了予定だけが案内されている資格は含めないこと

「世界中の情報系資格すべて」を保証するものではなく、上記の条件で
2026年7月30日に公式情報を確認できた主要資格を収録する。

今回のデータは148資格で、IPA、LPI-Japan、Python、JDLA、統計検定などの
国内資格に加え、AWS、Google Cloud、Cisco、CompTIA、Microsoft、Oracle、
CNCF / Linux Foundation、HashiCorpの現行資格を対象にしている。

## ノード

1つのノードは1つの資格を表し、主な分野を色で表す。ノードの大きさは
資格によらず統一する。異なる主催団体を横断して比較できる共通の難易度基準が
ないため、難易度は可視化に使用しない。

```text
半径 = 18
```

各ノードには公式資格ページ、公式試験範囲ページ、共通語彙で整理した
試験トピックを保存する。

## 接続

接続は取得順や推奨順ではなく、公式試験範囲の共通性を表す。

1. 2資格の共通トピックを求める。
2. 共通トピックが2個未満なら接続しない。
3. 共通トピックが2個以上なら、Jaccard係数で関連度を求める。
4. 画面で選択した関連度以上の関係を表示する。
5. 線の太さは関連度で決める。

```text
関連度 = 共通トピック数 ÷ 2資格が持つトピックの合計種類数

25%未満: 1px
25%以上: 1.5px
35%以上: 2.5px
45%以上: 4px
55%以上: 6px
65%以上: 8px
80%以上: 11px
```

線を選択すると、共通トピック、共通項目数、関連度、接続理由、両資格の
公式根拠URLを表示する。関連度の基準は30%、40%、45%、60%から
選択でき、初期値は40%とする。共通トピック2個以上の関係候補は削除せず
保持する。

## 更新方法

`src/data/qualification_catalog.json`を修正した後、次を実行する。

```bash
npm run generate:data
```

これにより`qualification_nodes.csv`と`qualification_edges.csv`が再生成される。
